## 实施范围

### 1. 账号与用户设置

- 增加用户名、密码自主注册，注册只能创建普通读者。沿用现有用户名、密码校验及密码哈希，增加注册限流和重复账号反馈。自主注册不要求再次修改刚设置的密码。
- 保留管理员开通和重置密码后的首次改密要求，以及停用账号、会话失效、管理员独立入口与会话边界。兼容现有需要登录的读者部署模式。
- 公开站点继续允许匿名检索、阅读及现有下载，同时开放登录。收藏和个人设置必须登录；普通读者不得访问管理功能。保留现有 Agent 接口及显式获取动作的原有权限契约。
- 完成注册、登录、账户菜单和用户设置页面。设置只含账号信息、修改密码、主题、语言及退出登录；忘记密码仍联系管理员重置。
- 主题、语言保存到账号并跨设备恢复。首次登录且无云端偏好时采用当前浏览器偏好；已有云端偏好优先。登录期间的修改同步到账号，保存失败明确反馈；退出后恢复浏览器匿名偏好。
- 扩展现有会话接口，新增注册接口及 `/api/me/settings` 读写接口。个人接口从会话取得用户，不接受客户端指定其他用户。写操作校验 Origin 与 CSRF；注册沿用登录前防护流程。个人响应不进入公共缓存。
- 在现有账号存储中增量增加偏好及收藏表，保留旧账号、密码、权限和会话数据。迁移可重复运行且失败不留部分变更；生产迁移不在本轮执行。

### 2. 收藏

- IEEE、arXiv 搜索结果和详情页提供收藏/取消收藏入口。匿名点击引导登录，完成后返回原页面；不因登录暗中提交其他业务动作。
- 增加“我的收藏”页面，按收藏时间倒序，支持来源筛选、分页、多选、全选当前已加载条目、清空选择和批量取消收藏。筛选切换时清空选择，追加加载时保留已选项，离开收藏页不保留隐藏选择。
- 收藏随账号保存。唯一身份包含来源、论文 ID 和版本；IEEE 不带版本，arXiv 固定收藏时选定的实际版本。同一论文不同版本可分别收藏，列表显示版本。
- 从收藏进入详情时保持来源与版本。论文或指定版本暂不可读取时保留收藏并显示状态，不静默改用最新版。
- 新增 `/api/me/favorites` 查询、添加和移除接口，支持批量操作及分页。重复收藏幂等，服务端校验论文身份；查询、移除及下载均限定当前用户。
- 收藏不复制全文或原文件、不改变论文元数据，不触发获取、解析或采集。

### 3. 跨来源单 ZIP 下载

- 收藏页一次选择最多 100 篇，将不同来源、不同 arXiv 版本的已缓存 PDF 放入一个 ZIP。超过上限明确提示重新选择，不静默截断或拆包；收藏总数和普通多选不受该下载上限限制。
- 复用已有可用性检查、命名与下载弹窗；网站侧新增统一归档接口，接收当前用户的收藏条目 ID，由服务器解析对应缓存资源。新接口补充到接口文档，旧搜索页下载接口保持兼容。
- 复用已注册提供者的只读缓存文件接口，在服务器临时存储中生成 ZIP；不要求私有提供者新增协议。服务端只允许由已验证论文身份推导出的本应用缓存读取路由，不接受客户端 URL 或文件路径，不访问上游、不跟随外部重定向。
- 使用有界文件读写，避免把整包 PDF 放入内存。准备结果返回可下载数量、跳过条目与原因；有文件时给出一个归属当前用户的下载链接，没有文件时不返回空成功包。下载需重新验证会话与归属，临时文件有到期、失败及取消清理。
- 文件名保留来源、论文标识及 arXiv 版本，复用模板与非法字符处理，处理同名文件，确保不会覆盖。原始 PDF 字节不变。
- 缺失、受限、未打包、不可读取分别反馈。已知不可用条目可明确跳过；意外打包失败必须报错，不能冒充完整成功。下载开始不等于浏览器已下载完成。

### 4. 管理台重构

- 信息架构、布局、排版及交互由 Claude 按自己的审美重构，尽量与 CIRDC-Pro 现有风格一致。复用色彩、主题、字体、按钮、表单和状态组件，不要求沿用当前管理台布局。
- 完整保留更新范围预览、作业启动/恢复/重试、进度、日志、失败及受限记录、索引、服务预检、资源设置、维护状态、账户管理和审计。不得以重设计为由删除现有操作或隐藏失败。
- 自主注册与管理员开通的账号统一出现在账户管理中；保留开通、停用和重置密码能力。
- 账号、收藏及设置页采用一致设计；支持中英文、现有主题、键盘操作、可访问标签及桌面/手机布局。以分组、层级和留白表达结构，避免堆砌说明文字。

### 不增加的功能

不增加收藏夹层级、标签、笔记、分享、推荐、社交登录、邮件系统、头像上传或其他业务功能。阅读偏好中仅主题和语言跨设备同步；其他既有本地偏好保留原行为。不得改论文原始 HTML、TeX、复制源值或 PDF，不改元数据维护引擎、采集、私有提供者和其他仓库。

使用本分支现有独立开发环境及官方入口，不使用服务环境或生产账号库。已有环境可跳过 setup：

```sh
sh tools/web setup

```

读取 `website/demo/arxiv/README.md`：现有离线样本含 43 篇真实 arXiv、3 篇 IEEE 元数据和一篇已授权正文，无需生产数据库、私有配置或远程服务。端口被占用时改用空闲端口，不停止他人的服务。

现有 Demo 不支持账号写入、管理台或成功 PDF 下载，本轮必须补齐可独立运行的验证输入：

- 复用真实元数据和现有 Demo 入口，接入隔离账号、收藏和设置存储，尽量使用实际业务实现，不能只做前端假成功。测试数据仅在本轮工作目录生成，不进入正式状态目录。
- 管理台操作连接明确的隔离测试适配器，覆盖运行中、失败、受限及空数据；不得调用真实作业启动或恢复接口。
- 增加明确标注为测试材料的 PDF 和本地缓存提供者，覆盖 IEEE、arXiv 多版本及缺失状态。不得伪造为真实论文 PDF，也不下载新的论文来补测试样本。
- Demo 只放行本轮个人功能所需的隔离写入；来源获取、元数据写入和其他采集入口继续禁用。同步更新 Demo 与生产接口差异说明。

测试 PDF/隔离适配器通过，不代表生产缓存、生产数据规模或生产部署已验证。分别记录通过、跳过、既有失败与未验证项。
