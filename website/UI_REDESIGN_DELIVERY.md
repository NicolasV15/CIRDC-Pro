# Website 前端美化与体验重构交付说明

> 对应计划：`WEBSITE_UI_REDESIGN_PLAN.md`。基线：`e7d55b5`（含功能基线 `8c1a3e1`）。
> 改动范围：`website/web/`（页面、组件、样式、视觉资源、相关测试），以及 `website/docs/web.md` 中三处随界面变化的描述。未修改后端、数据库、采集、安装器、部署代码或接口契约。

## 设计要点

- 统一视觉语言：主题色板（6 套 + 跟随系统）保持不变，新增一层设计令牌（圆角、阴影、间距、控件高度、字体）；界面使用系统无衬线字体，论文标题、摘要与正文使用衬线字体以提升阅读感；统一线性图标集取代 `↗ × ⌕ ▸` 等字符图标；新品牌标识与 favicon。
- 检索页以“查找—筛选—比较”为主线：大检索框置顶，左侧筛选栏（窄屏折叠为「筛选」），结果上方集中显示「当前条件」并可逐个移除；结果行标题优先，年份/类型/刊会/出版物合并为一行，操作行收敛为「引用」「资料」与论文编号。
- 详情页以“阅读理解—引用获取”为主线：标题下方集中放置「引用」「阅读 PDF」「IEEE Xplore 原文」，正文、目录、参考文献、被引、关键词顺序与行为不变。
- 顶栏精简：用户名、修改密码、退出合并为账户菜单；窄屏导航收进菜单，语言切换在所有宽度直接可见。
- 文案精简：删除重复的眉标与提示（如“修改条件后，点击右侧「检索」应用”改为筛选栏内「应用筛选」并提示未应用更改），保留状态、权限、错误原因与统计说明。

## 结构调整

- 原 `main.tsx` 拆分为 `AppHeader`、`ReaderPage`、`PaperDetail`、`AdminPage`、`AuthPages`、`Overview` 及共享的 `api`、`types`、`format`、`Icon`；业务处理、请求参数、轮询与重试策略按原逻辑迁移。
- `AgentAccess.tsx` 更名为 `AgentAccessPage.tsx`：原文件名与 `agentAccess.ts` 仅大小写不同，在 macOS 等大小写不敏感文件系统上导致 `npm run build` 失败。
- `style.css` 重写为按区域组织的样式表，去除原有的大量 `#root` 覆盖规则。

## 测试调整

- `i18n.test.ts`：覆盖清单加入新拆分的组件文件。
- `searchStartup` / `venueFilters`：筛选栏在窄屏折叠，定位改为 `.filter-disclosure > summary` 并在需要时先展开；断言不变。
- `selectionCopy`：关闭格式预览后等待两帧再断言选区恢复。应用按设计在 `requestAnimationFrame` 中恢复选区，原测试在弹窗移除的同一时刻断言，存在时序竞争（基线在本机同样失败）；断言内容不变。
